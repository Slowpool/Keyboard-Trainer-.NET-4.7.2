Modes:
  - `word word word word word (repeating word)` - for newbies who only starts
  - `bought through out leak and ciri you (random words)` - a bit more difficult than the previous mode
  - `"Hello, dear diary!" - Amanda told John. (text)` - you can type and read some long story simultaneously
  - `54773 19387 374 75 387 293 5984 17493 (figures)` - for those who deal with digits a lot
  - `own text` - you can past anything you want in dialog window and type it
  - `& <~ [@/ -)! (>@-:;; (.; <, '{'>}^/>}, ~ (characters)` - well, now it is becoming interesting (the hardest mode i think)
  - `You\'re burning and shining like a meteor (song)` - personally i used it for typing of my own song translations, though that's the same as (text) mode

Features:
  - `language picking`
  - `hardcore` - any mistake resets the whole current line progress
  - `walkthrough` - traversing all modes (except `own text`) this way: completing of N specified lines in current mode will switch automatically to next mode. convenient for regular trainings
  - `minimal typing speed` - if you type slower, the whole line is reset. according to specified speed, app calculates the maximal interval between two characters and compares it with your intervals during typing

Hint:
  - using the `walkthorugh` in combo with `hardcore` and `minimal typing speed` can turn you into a beast of keyboard
